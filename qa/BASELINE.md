## 硬缺陷（可复现，逐条对应截图）

1. **字体走 Google Fonts，中国大陆基本不可达。** `<style>` 首行 `@import` 阻塞整页样式：屏蔽后 LCP = **14.9 秒**。他自己的读者在中国。
2. 字体 CSS 单文件 **124KB**（Noto Sans SC 全量 CJK），LCP 3.7s 的主因。
3. `🐈‍⬛`（ZWJ 序列）在 Windows 渲染成 **豆腐块**：`有一只叫干杯 🐈 的小黑猫` —— 全站最私人的一句话带着乱码。
4. **16 处文字 < 11px**（10.4px 的分组标题、9.6px 的访问计数）。中文 10.4px 不可读。
5. `AI & 大模型` 里的 `&` 用 Space Mono 小字号渲染成 **"G"**（`AI G 大模型`）。
6. **无 `prefers-reduced-motion` 降级**，全站动画对动敏感人群不友好，也是评审硬指标。
7. 移动端 **5 个点击区 < 40px**；导航 4 个链接在 390px 下无收纳。
8. 时间线第三条标题是 `?`（H3），语义与 SEO 双输。
9. 技能区 6 格网格只填了 6 格中的 4+2，右下角留两个空格子 —— 视觉上像没做完。
10. Hero 右半屏、时间线右半屏、终端框内 —— **大量无内容空白**，没有视觉承担物。
11. 全站 **零作品、零 GitHub 链接、零可验证事实**。只有形容词。对一个想靠 GitHub 吃饭的人来说，主页没有把他的流量导去任何地方。
12. 无 `og:image`（分享出去是空白卡片）。

## 结论

这不是"打磨不够"，是**方向不对**：现在的设计语言与他的真实生活没有任何绑定。
获奖作品靠的是一个只属于作者的原创概念 + 一个贯穿全站的签名交互 + 真实内容。
下一稿的设计方向见 `DESIGN.md`。

## 还差的两件事，以及各归谁

1. **Content 8.8 → ≥ 9.0（要他给材料）。** 需要三四句只有他知道、且他愿意公开的真话。我可以问、可以排版、可以做成一整屏，但不能替他编——上一版就是编了"猫不在家"才被他打回来。
2. **线上 LCP 稳定进 2500ms（要他点一下控制台）。** 归因已经量清楚（`qa/ROUND4.md §6`）：源站 0.9ms、字体全在边缘 HIT、LCP 与 HTML TTFB 基本 1:1，压不住的是 HTML 每跳穿隧道。要么他批准一条 Cloudflare Cache Rule，要么授权我用他已登录的浏览器代点。代码侧该挤的这轮已经挤完：Instrument Serif 42KB→5KB 之后，线上首访的字体尾巴从 4877ms 缩到 2014ms。

现状说明：v3 已经按他先前那句"部署，并线上复检"上线（本地与线上 `md5` 逐位一致）。
按"达不到就继续改，不交出去"的标准，这一轮**不算收工**——上面两条一个等材料、一个等批准。
